# Changelog

## 0.1.0 - Milestone 0/1 Foundation

- Added project structure.
- Added Dhan HTTP client abstraction and deterministic mock client.
- Added downloader chunk planner and resumable manifest.
- Added raw response archive, metadata store, Parquet store, and DuckDB catalog.
- Added validation and normalization for Dhan expired-options rolling data.
- Added CLI scaffolding for download, validate, and status.
- Added tests for chunking, validation, mock pipeline, metadata, Parquet, and DuckDB querying.
